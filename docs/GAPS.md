## External ecosystem protocol assessment: walt.id v2 vs Inji — 25 October 2026

Following the gating criteria (*"Add one independently implemented external issuer or verifier profile only if protocol versions align"*), Person 3 and Person 4 evaluated **walt.id Identity toolkit v2 (`Issuer2` / `Verifier2`, release `v1.2.0`)** against the pinned MOSIP Inji stack (`inji-certify v0.14.0`, `inji-verify v0.18.2`).

1. **Protocol Specifications Divergence:**
   - **OpenID4VCI:** walt.id `Issuer2` implements final OpenID4VCI 1.0 (Draft 14+ / Final), enforcing `credential_configurations_supported` metadata, batch issuance schemas, and mandatory PAR. Inji Certify implements Draft 13 with `credential_definitions` and draft-era endpoints.
   - **OpenID4VP Query:** walt.id `Verifier2` enforces Digital Credentials Query Language (DCQL) and compact signed Request Objects. Inji Verify and Inji Wallet strictly require DIF Presentation Exchange 2.0 (`presentation_definition`).
   - **Response Mode & Encryption:** walt.id `Verifier2` enforces encrypted response mode (`direct_post.jwt` via JWE). Inji Verify does not support response decryption, requiring cleartext `direct_post` with unencrypted JWS payloads.
   - **Trust Architecture:** walt.id relies on European EUDI / ETSI trust anchors and `x5c` leaf trust lists, whereas Inji Verify requires MOSIP Keymanager trust anchors.

2. **Stopping Rule Application:**
   Because automated cross-ecosystem interop cannot function without non-standard DCQL-to-PEX translation shims, JWE decryption bridges, and draft-13/14 protocol adapters, Person 3 invoked the project stopping rule:
   > *"Stop an exploratory track when it cannot produce a reviewable result before the working code freeze; mark it `not_implemented` or `not_tested`."*

3. **Status:**
   The cross-ecosystem matrix cell for walt.id is explicitly designated **`not_tested (protocol draft mismatch: DCQL/encrypted vs DIF PE/cleartext)`**. This is an architectural interoperability finding (G-08), not a defect in either product. No speculative driver code or synthetic pass was fabricated.
